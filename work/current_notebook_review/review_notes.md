# 附件 Notebook 检查与后续优化思路

检查对象：用户提供的 `notebook3 (1).ipynb`。其配置为 Research 2.0.0，共 22 个单元，代码单元没有执行计数、输出或模型权重。它不能单独提供已经训练好的测试集预测。

## 本次已处理的问题

1. **NumPy / PyTorch 布尔标志兼容性。** 实际在本机 PyTorch 2.5.1 + CUDA 12.1 运行时，细裁剪的 `crop_was_enlarged` 是 NumPy 布尔标量，`torch.tensor(crop_was_enlarged)` 抛出 TypeError。已将三个裁剪标志显式转换成 Python `bool` 并指定 `torch.bool`。重新训练使用独立目录，旧失败运行未参与预测。
2. **早停与最终推理不一致。** 附件用无 TTA 误差选轮数，推理却启用水平翻转 TTA。升级版对内部早停采用相同的原图坐标还原与 TTA 解码。
3. **重训学习率轨迹改变。** 附件在早停选定轮数后，将余弦调度周期压缩到该轮数；重训前几轮的学习率与选轮阶段不再一致。升级版保留配置中的完整调度周期，仅截断训练轮数。不同训练集大小仍会使每轮更新次数不同，不能声称优化器轨迹完全相同。
4. **细裁剪尺度分布不一致。** 附件的 OOF 细训练主要使用固定裁剪大小，推理则使用可变的校准半径。升级版在每个外层训练折内部比较固定与多尺度训练，按内部早停集选策略；外层验证标签不参与选择。训练时窗口遗漏目标可扩大窗口，但验证和测试时绝不使用真值修复裁剪。
5. **小校准集上回退规则不稳。** 附件最多搜索 3×3 个阈值组合，极小改善即可采用。升级版只用三个预定候选，要求足够独立组数、至少 1 像素且 1% 的校准误差改善，且 P90 不恶化。这个约束只能减轻过拟合，不能提供泛化保证。
6. **缓存和中断排查。** 升级版保存阶段日志并校验配置、代码、数据和文件 SHA256。仅复用已完成且一致的阶段；中途阶段需重训，不能称为优化器断点续训。

上述 2–6 项采用之前已审查的 3.0 流程；本次新增了真实 GPU 训练中发现的布尔兼容性修复，并重新训练生成实际提交。没有以同预算重新训练附件原版，所以本次不能证明新版本相对原版提高了多少。

## 进一步优化的优先顺序

### 1. 先改善训练数据利用率

总共只有 80 张训练图；每个外层折有 64 张，预留独立校准后最终网络通常只用约 48 张。科研用的严格校准评估和竞赛最终拟合可以分别设计。下一轮先增加一个不依赖半径校准的固定 ROI 分支，允许它在外层训练折内用更多图像拟合，并在相同外层划分上比较。在全部数据上重训模型后，不应直接沿用另一套留出模型的校准参数并宣称覆盖率有效。

### 2. 在内部验证中比较细定位分辨率和损失权重

本次 256/256 是明确的计算预算，并非已证明的最优分辨率。下一轮固定其余设置，比较细输入 256 与 384，粗输入 256 与 512；同时将热图 Gaussian sigma 换算到实际裁剪像素，避免提高分辨率时无意改变监督平滑尺度。检查细模型的坐标损失梯度占比，再比较坐标项加权或后期精修。DSNT 论文本身支持从热图连续回归坐标，但并不证明本数据上的某个分辨率最优：[Numerical Coordinate Regression with Convolutional Neural Networks](https://arxiv.org/abs/1801.07372)。

### 3. 针对真实失败类型做增强

保存每张 OOF 图的欧氏误差、原图尺寸、视野边缘位置、局部对比度、裁剪覆盖和五折预测分歧。优先区分：粗中心错位导致裁剪遗漏、ROI 太小造成上下文丢失、低对比度、图像尺寸分布差异。再在内部开发集比较温和 gamma / 对比度增强、预测中心扰动和训练尺度范围。不要看到外层个别样本失败就修改其标签或手调测试坐标。

### 4. 更换预训练模型应作为独立对照

小数据下可测试眼底预训练编码器或更强的通用编码器，加同一定位头，并保持数据划分与训练预算一致。RETFound 的原论文表明眼底自监督预训练可用于少标注的疾病检测适配；它不是本比赛中心凹定位提升的直接证据：[RETFound，Nature 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10550819/)。当前提交仍是官方 ImageNet ResNet18 初始化，不使用未验证的新权重。

### 5. 多种子与融合在方案确定后再做

当前使用五个不同训练折的均值融合。下一步可对最终预定方案增加 2–3 个随机种子，报告每种子的 OOF 指标和模型分歧，再检验等权融合是否降低大误差。若要学习融合权重，只能在内部开发/校准数据上选择；不能用测试答案或排行榜反复调权。
