# 8.2 基线的 OOF 误差诊断

2026-10-27，只读分析冻结的 8.2 基线及其两个组成分支。没有运行 GPU、修改训练或门槛，也没有读取测试标签或从测试预测猜答案。8.2 是用户反馈的 Kaggle 成绩；下面的误差均来自 80 张有标签训练图的 OOF。

## 已证实：RMSE 主要由少数大误差样本决定

8.2 基线 OOF 坐标 RMSE 为 **28.7624px**，中位欧氏误差为 **13.1059px**。坐标 RMSE 使用 `sqrt(Σ(dx²+dy²)/(2×80))`；下表的单图误差使用欧氏距离，二者不是同一个指标。

| 图像 ID | 单图欧氏误差 / px | 占总平方误差比例 |
|---|---:|---:|
| 49 | 199.8400 | 30.17% |
| 72 | 155.4786 | 18.26% |
| 14 | 90.8345 | 6.23% |
| 44 | 81.7681 | 5.05% |
| 34 | 78.8981 | 4.70% |

仅 49、72 两图（2.5% 样本）贡献 **48.43%** 总平方误差；前五图贡献 **64.42%**。因此整体 RMSE 的变化可能主要来自少数尾部样本，不能只根据总体分数推断大多数图都同等改善。本报告保留所有样本计算正式指标，没有删除大误差图来提高分数。

## 已证实：两个组成分支都存在相同的 ROI 遗漏

原版与 seed10000 分支各自的 B4 OOF ROI 都覆盖 **78/80（97.5%）**，遗漏均为 49、72。两分支的 80 个 OOF ROI 都触发最小窗口限制，即实际使用原图短边的 15%；49、72 的窗口边长均为 300px。当前观察到的 OOF 中，自适应半径没有产生不同窗口尺寸。

8.2 是两个分支预测坐标的融合，没有一个统一的物理裁剪窗口；因此 97.5% 是各组成分支的覆盖率，不能直接称为“融合模型的 ROI 覆盖率”。

| 分支 | 图 | coarse 误差 / px | fine/B4 误差 / px | 现有窗口内最佳可能误差下界 / px |
|---|---:|---:|---:|---:|
| 原版 | 49 | 202.059 | 215.964 | 42.313 |
| 原版 | 72 | 185.776 | 158.586 | 35.217 |
| seed10000 | 49 | 184.252 | 153.650 | 34.249 |
| seed10000 | 72 | 184.390 | 146.195 | 20.530 |

下界是标注点到 coarse 中心方形窗口的最短距离。窗口遗漏意味着任何只在该窗口内输出坐标的 fine 模型都不可能实现零误差；但实际误差明显高于这个下界，说明不能把全部误差归因于裁剪遗漏。局部识别或解码仍有改进空间。

同样不能简单判断“fine 总比 coarse 好”：图 34 在原版中 coarse 误差为 33.66px，fine 为 94.97px，而 seed10000 中二者约为 46.15px 和 41.58px。精修有时纠正粗定位，有时反而偏离。

## 已证实：当前回退机制没有发挥保护作用

两个组成分支的五折回退规则全部 `enabled=false`，80 张 OOF 的实际回退率都为 **0%**。各折校准集上的三组预定候选规则也都没有触发回退，因而没有达到至少 1px 且 1% 改善、P90 不恶化的启用条件。这不是程序忘记调用回退，而是当前规则特征和门槛没有识别出需要回退的情况。

回退依据是：预测距裁剪边界的比例过小，或者 coarse/fine 坐标差除以 coarse 热图扩散程度后过大。现有候选的边界门槛不超过 0.08，标准化分歧门槛为 2、4 或极大值。

49、72 的边界比例分别落在 **0.262–0.443**，标准化分歧仅 **0.154–0.523**，所以即便直接启用这些候选阈值也不会捕获这两例。**两阶段可以同时预测错误但彼此较一致，而且预测并不靠近窗口边缘。** 这些具体数值证明“低分歧/不贴边”并不能保证本例定位正确；不能进一步把它泛化为所有不确定性方法均无效。

## 未来假设与独立实验方向

以下尚未由本次诊断证明，也不改变当前 sigma=1.5 实验及其已固定门槛：

1. **先改善尾部失效的处理。** 可另设一次对照，研究预测驱动的第二窗口或更广上下文分支，尝试发现“coarse 与 fine 一致地偏错”的情况。必须在内部训练/早停数据设计规则，不能为 49、72 写特例，也不能根据外层真值直接选择裁剪大小。
2. **区分窗口遗漏与局部识别错误。** 保存完整 coarse/fine 热图和原图裁剪可视化，再检查是否存在多峰、背景纹理吸引或定位信息不足。仅凭已有坐标不能证明这些视觉原因，更不能据此断言病变、图像质量或标注错误。
3. **评估新的风险特征。** 当前热图扩散只是预测分布宽度，不是校准后的真实定位误差或完整认知不确定性。可在内部交叉预测上研究尺度稳定性、不同模型的一致性或窗口重定位的一致性；需要单独验证，不能直接假设新门槛会提高成绩。

## 为什么本地分数不能直接预测线上分数

已观察到的事实是：384 版本 OOF 约 22.04、用户反馈线上约 12.4；原版 OOF 约 32.03、线上 8.9；当前集成 OOF 28.76、线上 8.2。已有例子显示本地排名与线上排名不总一致。

可能的解释包括：80 张训练图的尾部样本占比高；20 张测试图及实际计分子集的组成可能不同；同一外层划分被多轮开发反复查看；OOF 每图只来自其对应的一个外层折（该折内部仍有两种子融合），而测试预测平均五个折；未知患者分组、图像来源差异或标签噪声也可能影响表现。**这些只是合理可能性，现有记录不足以确定哪一项是原因。** 不能从 OOF 28.76 换算或承诺一个新的 Kaggle 分数，也不能以线上反馈反推任何测试图的正确坐标。
