# 宽窗口单分支精修：两套五折与全训练组重训

主划分提交方案的 OOF 坐标 RMSE 降低 1.893555px。 最终 CSV 与上一轮不同，40 个坐标中有 40 个改变。 真实线上成绩在训练与选型时未知。本模型训练与选择流程不读取外部测试参考标签；同会话另有用户指定人工诊断支路，独立保存，不进入本实验。本报告生成器也不读取该诊断支路或外部参考标签。

## 实际改动与数据边界

保留原三通道 ImageNet ResNet18，将 fine 改为图像短边 **0.25** 的窗口、384×384 输入、96×96 热图、sigma=1.5。沿用两套分组种子2026/2027及已核验的粗定位模型与图像留出裁剪中心。早停只在内部 stopping 组、真实部署尺度下，以原图坐标 RMSE 和同一 TTA 方式选轮。没有重新训练粗网络，也没有添加新回退分类器。

每折包含 `wide_select → wide_dev → 冻结接入决策 → wide_full`。WIDE_DEV 只使用原开发组47–48张；WIDE_FULL在固定轮数下加入原校准组，合计64张非外层图。两套五折共 **30 个新训练阶段**。DEV/FULL同初始化种子、同epoch数，但FULL每轮样本和实际优化步数更多；这是训练数据量与更新预算的联合对照，不能把收益全部归因于新增图像。

原校准组先比较冻结旧 SINGLE 与 WIDE_DEV，要求 RMSE 至少降低 **0.5px 且2%**，并且 P90 不升高；通过与否在 FULL 重训前保存。此组随后成为 FULL 训练数据，因此 **FULL没有独立校准组**。旧半径、风险回退及覆盖率校准不会移植到新FULL模型。OOF外层图始终不参与上述训练或选择。

本次对照同时改变窗口和输入/热图尺寸，不能称为单因素“增加分辨率”。短边2000px的例子中，旧300px窗口变500px；原图每输入像素由1.171875变1.302083，sigma物理宽度由7.114955px变7.874178px，训练中心抖动标准差由24.0px变40.0px。训练时保留并记录目标出框扩大机制；验证和推理不使用标签修复裁剪。

## 训练结果

GPU：NVIDIA GeForce RTX 4060 Laptop GPU；新增训练与折内推理耗时 14.73 分钟，记录的峰值CUDA分配内存 878.99MB。独立验证重载30个最终网络（20个新DEV/FULL和10个旧SINGLE），状态PASS；测试图进入训练或选型的数量为0。

验证过程保留了一次失败记录：首次旧 SINGLE OOF 重载差异为 0.002197265625px，超过未放宽的 0.001px 阈值。原因是复制旧 ROI CSV 时默认浮点解析把窗口边长 `290.09999999999997` 写成 `290.1`；相同模型、完整帧及批次下，改用原生产者 ROI 文件并以 round-trip 解析重放，差异恢复为 0.0px。仅修正验证器对继承旧 OOF/test 预测的输入重放；模型、训练引擎、提交 CSV、接入门槛和误差容差均未改变。首次失败原样保留；本报告的 PASS 来自修正后完整重跑，相关证据随 ZIP 保存。
